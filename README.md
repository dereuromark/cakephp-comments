Comments plugin for CakePHP applications.

Read the [CakePHP 6 branch documentation](docs/guide/installation.md), starting with
[Installation](docs/guide/installation.md) and [Getting started](docs/guide/getting-started.md).
This development branch requires PHP 8.5. The
[published website](https://dereuromark.github.io/cakephp-comments/) covers CakePHP 5.

The plugin supports forms posting to its public controller or to an application action through the Comment component. It includes a Comments association and an admin interface. Your application supplies authentication and public visibility rules.
